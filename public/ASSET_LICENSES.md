# 에셋 및 의존성 기록

작성일: 2026-10-09. 외부 모델·텍스처·폰트·음원 파일은 다운로드하거나 사용하지 않았습니다. Kenney 후보 팩과 Meshy 등 생성 API도 사용하지 않았습니다. 따라서 외부 모델 로더, CDN 원본 참조, 로드 실패 시 에셋 교체가 필요한 경로는 없습니다. 모든 외형은 항상 로컬 코드로 생성합니다. 효과음과 배경음은 `src/audio.js`에서 Web Audio 오실레이터로 자체 합성합니다.

별도의 모델·텍스처 원본 및 가공 파일이 없습니다. 모델 전방은 +Z, 타일 간격은 3.4이며 외형 생성 함수와 전투 규칙을 분리했습니다. 글꼴은 PC 시스템에 설치된 Segoe UI, 맑은 고딕, Georgia 또는 시스템 대체 글꼴을 사용합니다. 글꼴 파일을 포함하거나 외부 서버에서 로드하지 않습니다. 새 냉각탑·관통포·방호 시설·공방, 적의 추가 역할 모델과 해역 지형은 `src/models.js`에서 자체 제작했습니다. 합성 음향도 별도 외부 라이선스가 필요한 음원 파일을 사용하지 않습니다.

정확한 의존성 목록과 해시는 `package-lock.json`에 있습니다. 런타임에 번들되는 Three.js의 원본 MIT 고지는 `public/licenses/THREE-LICENSE.txt`에 보관하며 빌드에 함께 복사됩니다. 다른 개발용 패키지의 라이선스는 npm 설치 파일에 포함됩니다. 라이브러리와 외부 아트 에셋은 서로 다른 항목입니다. 이 문서는 프로젝트 전체의 새 라이선스를 선언하지 않습니다.

Windows 실행 폴더에는 Electron 공급 바이너리의 원본 `LICENSE`와 `LICENSES.chromium.html`을 그대로 포함합니다. 후자는 내장 Chromium, Node.js 24.21.0 및 구성요소별 저작권·라이선스 고지를 포함합니다. 게임의 Three.js 고지는 실행 폴더의 `licenses/THREE-LICENSE.txt`와 번들 내부에 함께 있습니다. 개발용 Vite·Playwright·packager와 테스트 저장·개인 프로필·`node_modules`는 실행 패키지에 넣지 않습니다. Electron 런타임은 공식 배포의 정확한 버전·아키텍처 ZIP과 체크섬으로 설치하며 캐시는 프로젝트 `.electron-cache/`에 둡니다.
